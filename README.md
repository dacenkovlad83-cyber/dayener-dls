# dayener dls (Fabric, Minecraft 26.2)

Клиентский мод: автоматически бьёт сущность под прицелом, когда откат атаки готов.

> ⚠️ На публичных серверах использование таких модов нарушает правила и может привести к бану.
> Мод предназначен для одиночной игры и собственных серверов.

## Требования

- Minecraft **26.2**
- Fabric Loader **0.20.1+**
- Fabric API **0.161.0+26.2**
- Java **25**

## Сборка

```powershell
$env:JAVA_HOME='C:\Program Files\Eclipse Adoptium\jdk-25.0.3.9-hotspot'
.\gradlew.bat build
```

Готовый jar: `build/libs/dayener-dls-1.0.0.jar` → положить в папку `mods`.

Запуск дев-клиента: `.\gradlew.bat runClient`

## Управление

| Клавиша | Действие |
|---|---|
| `R` | Включить / выключить TriggerBot |
| `Right Shift` | Открыть / закрыть меню dayener dls |
| `G` | Добавить / убрать игрока под прицелом в вайтлист |

Все бинды лежат в отдельном разделе **«dayener dls»**: Настройки → Управление → Назначение клавиш.
Клавишу меню можно сменить в **Interface**, клавишу TriggerBot — в его настройках (ПКМ по модулю → «Бинд»).

## Меню (`Right Shift`)

Полупрозрачное окно с полностью скруглёнными углами, плавно появляется при открытии. Слева категории:
**Combat, Player, Visuals, Movement** (с иконками: меч, игрок, звезда, нога), а **Alt Manager** и **Interface** — в самом низу. Справа сверху — **поиск**.

- **ПКМ по категории** — открыть её модули посередине.
- **ЛКМ по модулю** — включить / выключить. **ПКМ по модулю** — плавно выдвинуть / спрятать настройки.
- **Бинд есть у каждого модуля** (в его настройках): нажми на чип «Бинд» и клавишу или боковую кнопку мыши.
  Backspace или ПКМ по чипу — убрать бинд. Бинд показывается рядом с названием модуля.

Модули:

- **Combat → TriggerBot** — бинд, режим атаки, цели, дистанция, CPS, задержка, видимость, подсветка, вайтлист.
- **Combat → AutoTotem** — кладёт тотем во вторую руку, когда HP ниже порога, рядом враг с булавой или
  кристалл края (дальность настраивается). Перед каждой сменой случайная задержка 50–250 мс (каждый раз новая),
  при взятии тотема игрок на 1 тик останавливается.
- **Player → AutoEat** — ест лучшую еду из хотбара при голоде ниже порога; «Перестать копать, чтобы поесть».
- **Player → AutoLeave** — выход при низком HP или когда чужой игрок ближе дистанции. После выхода выключается.
- **Player → ItemScroller** — Shift + ЛКМ, проведённая по слотам, или колесо мыши над слотом быстро перекладывает
  предметы; задержка между кликами 1–50 мс.
- **Player → NoJumpDelay** — без задержки между прыжками при зажатом пробеле.
- **Visuals → Fullbright / NameTags / NoRender** — яркость, таблички с донатом и бронёй, скрытие эффектов.
- **Visuals → TargetESP** — крутящийся ромб из уголков на цели (цель TriggerBot или моб/игрок под прицелом);
  размер, скорость вращения, белый или цвет меню.
- **Visuals → CustomHands** — режим рук (обе / только правая / только левая) и View Model: положение правой
  и левой руки по X, Y, Z, кнопка сброса.
- **Movement → AutoSprint** — бег при движении вперёд.
- **Movement → InvMove** — ходить с открытым инвентарём, сундуком или этим меню.
- **Movement → Freecam** — свободная камера; скорость по X/Z и по Y настраивается. Пробел / Shift — вверх / вниз,
  Ctrl — быстрее. Игрок стоит на месте. Не сохраняется после перезахода.
- **Movement → AirStuck** — зависание в воздухе. Не сохраняется после перезахода.
- **Movement → ElytraSwap** — отдельные клавиши: смена элитр ↔ нагрудник и запуск фейерверка из инвентаря
  (ракета работает в полёте на элитрах). Задержка 75 мс и пауза 1 тик. Ничего не выбрасывается: если места нет,
  элитры кладутся в свободный слот справа/слева от выбранного, затем в любой свободный, затем во вторую руку.
- **Alt Manager** — строка ввода ника и кнопка «Добавить» (можно несколько ников через пробел или запятую).
  Клик по нику — заходить под ним (офлайн-ник, работает на серверах без лицензии), × — удалить.
  «Основной аккаунт» — твой Microsoft-аккаунт из лаунчера, вернуться на него можно одним кликом.
- **Interface** — клавиша меню, цвет меню (ползунок оттенка + сброс), непрозрачность, HUD.
- **Interface → Watermark** — плашка с логотипом «D»: свой ник (можно вписать), FPS, время сессии, координаты,
  пинг, TPS сервера и скорость (BPS). Каждый пункт включается отдельно, размер 50–200%. Открой чат и перетащи
  плашку мышкой.

- **Interface → ArmorHUD** — твоя броня (шлем → ботинки) с прочностью: цвет от зелёного к красному,
  мигает, когда вещь почти сломана. Настройки: вертикально / горизонтально, проценты или число прочности,
  предметы в руках, фон, размер 50–200%. По умолчанию стоит над хотбаром; открой чат и перетащи мышкой,
  «Сбросить» возвращает на место.

## Настройки

Меню (`Right Shift`) или файл `config/triggerbot.json`:

- **Режим атаки** — `Выкл` (бить как обычно), `Только криты` (бить только в крит-окне),
  `Смарт` (на земле — обычные удары, в прыжке — только криты).
- **Range** — максимальная дистанция атаки (1–6 блоков).
- **Min CPS / Max CPS** — ограничение скорости ударов (1–20 в секунду).
- **Random delay** — случайный интервал между ударами.
- **Players / Hostile mobs / Passive mobs** — по кому бить.
- **Line of sight** — требовать прямую видимость цели.
- **Show HUD** — компактная плашка состояния и текущей цели.
- **Highlight target** — подсветка хитбокса цели (зелёная — удар готов, жёлтая — откат/ждёт крит).
- **Friends** — вайтлист игроков, по которым мод не бьёт.

## Как это работает

Каждый клиентский тик мод смотрит на `Minecraft.hitResult`:

1. Если под прицелом нет сущности — ничего не делает.
2. Проверяет фильтры: тип цели, вайтлист, дистанция, видимость.
3. Ждёт полного заряда атаки, соблюдения CPS-лимита и (в крит-режимах) условий крита.
4. Вызывает `MultiPlayerGameMode.attack(...)` + `LocalPlayer.swing(...)` — это ровно те же действия, что и при обычном клике.

Крит считается по ванильным условиям: падение (`fallDistance > 0`), не на земле, не на
лестнице, не в воде, не пассажиром, не в спринте, без слепоты.

TriggerBot работает только на событиях Fabric API (`ClientTickEvents`, `HudElementRegistry`, `LevelRenderEvents`).
Fullbright и NoRender сделаны клиентскими миксинами (`triggerbot.client.mixins.json`): они меняют только отрисовку,
сами эффекты и игровая логика не трогаются.
